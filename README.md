# GitHub Achievements Lab

Repositorio público de práctica para aprender Git/GitHub y documentar el progreso de logros del perfil **SCAREDbelike**.

## Estado actual

| Logro | Estado del laboratorio | Evidencia |
| --- | --- | --- |
| Pull Shark | Objetivo Bronze superado | 20+ PR propios mergeados en este repositorio |
| YOLO | Flujo ejecutado | PR mergeado sin code review |
| Quickdraw | Flujo ejecutado | Issue abierto y cerrado en segundos |
| Heart On Your Sleeve | Intentado | Reacciones ❤️ añadidas a PRs |
| Open Sourcerer | Intentado | PRs propios mergeados en varios repositorios públicos |
| Pair Extraordinaire | Pendiente | Requiere una contribución real con coautor |
| Galaxy Brain | Pendiente | Requiere respuestas aceptadas en GitHub Discussions |
| Starstruck | Pendiente | Requiere estrellas de otras cuentas |
| Public Sponsor | Pendiente | Requiere GitHub Sponsors |

> GitHub puede tardar en reflejar algunos badges y algunos logros se encuentran en pruebas o pueden cambiar de disponibilidad.

## Pull Shark

Este laboratorio ya supera el umbral conocido del tier Bronze. La siguiente meta grande es Silver, que requiere muchas más PRs mergeadas.

## Qué hay en este repositorio

- Registro de prácticas con branches, commits, issues y pull requests.
- Archivos de práctica de Pull Shark.
- Guías de Git y GitHub.
- Notas de integración con Unity.
- Roadmap de logros pendientes.
- Evidencias de flujos Quickdraw y YOLO.

## Repositorios relacionados

- `appProforma`: proyecto Android con CI y mejoras integradas mediante pull request.
- `appMantenimiento`: proyecto Android con validaciones y CI integrados mediante pull request.

## Objetivo

Usar GitHub como un entorno real de aprendizaje: ramas pequeñas, commits claros, pull requests, revisiones, automatización y documentación.
